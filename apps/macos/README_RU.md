## Что это

Dikto Pro — это коммерческая русскоязычная версия open-source проекта
[Dikto](README.md). Под капотом — модель GigaAM от Сбера, оптимизированная
под русский язык и работающая нативно на Apple Silicon через MLX.

- Hotkey-диктовка в любое поле, где есть курсор
- Распознавание на устройстве (CPU/GPU Apple Silicon)
- Стриминг — слова появляются на лету, пока вы говорите
- Словарь технических терминов и собственных имён
- Триал 14 дней, потом — пожизненная лицензия

## Установка

1. Скачайте DMG с [dikto.itbeaver.co](https://dikto.itbeaver.co)
2. Откройте DMG, перетащите **Dikto Pro** в **Программы**
3. Запустите. При первом запуске macOS попросит разрешения:
   - **Микрофон** — без него не получится записать звук
   - **Универсальный доступ (Accessibility)** — нужен, чтобы вставить
     распознанный текст в текущее окно

После запуска в строке меню появится значок с волной — это и есть Dikto Pro.

## Как пользоваться

По умолчанию hotkey — **правый Option** (⌥, рядом со стрелочками). Зажмите,
скажите фразу, отпустите. Текст появится в активном поле через секунду.

| Что хочется сделать | Жест |
|---|---|
| Короткая фраза | Зажать → говорить → отпустить |
| Длинная диктовка | Двойное нажатие → говорить → одиночное нажатие = стоп |
| Скопировать последнюю диктовку | Меню значка → «Скопировать последнюю диктовку» |
| Поменять hotkey | Меню → «Открыть конфигурацию», в `config.json` поменять `keyCode` |

## Что отличает Dikto Pro от бесплатной Dikto

| | Dikto (free) | Dikto Pro RU |
|---|---|---|
| Цена | Бесплатно (MIT) | 1 990 ₽ пожизненная лицензия |
| Интерфейс | Английский с RU-локализацией | Полностью русский |
| Модель по умолчанию | Whisper base.en | GigaAM v3 (русский) |
| Триал | — | 14 дней без ограничений |
| Поддержка | GitHub Issues | Email + Telegram |
| Сервер активации | — | Есть (онлайн-проверка раз в 7 дней) |
| Аудио в облако | Никогда | Никогда |

**Важно**: платная версия отличается от бесплатной только русским опытом
«из коробки» и поддержкой. Само распознавание — тот же on-device движок.
Если вам комфортно с английским интерфейсом и настройкой через JSON —
free Dikto делает всё то же самое.

## Лицензия и приватность

- **Аудио и текст никогда не покидают ваш Mac.** Никаких облачных
  серверов транскрипции.
- Единственный сетевой запрос — проверка лицензионного ключа: один HTTPS
  при активации и один раз в 7 дней для контроля возврата/блокировки.
- В этом запросе уходит: ключ лицензии и анонимный SHA-256 хэш машинного
  UUID. Без email, без аудио, без транскрипций.
- Триал 14 дней — без регистрации и без сетевых запросов. Только локальная
  отметка о первом запуске.

## Системные требования

- macOS 14 Sonoma или новее
- Apple Silicon (M1 / M2 / M3 / M4 — да; Intel Mac — не поддерживается)
- 500 МБ свободного места (модель GigaAM ~250 МБ + приложение)
- 4 ГБ оперативной памяти (для стриминга комфортнее 8+)
