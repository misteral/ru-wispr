# Установка Dikto Pro

Подробная инструкция со скриншотами для тех, кто запускает Dikto Pro
впервые.

## Что вам понадобится

- Mac на Apple Silicon (M1 / M2 / M3 / M4)
- macOS 14 Sonoma или новее
- 5 минут времени

## Шаг 1 — Скачать и установить

1. Откройте https://dikto.itbeaver.co и нажмите **Скачать**.
2. В папке «Загрузки» появится файл `Dikto-Pro-1.0.0.dmg`. Откройте его
   двойным кликом.
3. В окне DMG перетащите иконку **Dikto Pro** в папку **Программы**.
4. Откройте папку «Программы» и запустите **Dikto Pro**.

> **Если macOS говорит «Невозможно открыть, разработчик не идентифицирован»:**
> приложение подписано Apple Developer ID и нотаризовано, но иногда первая
> проверка делает паузу. Откройте **Системные настройки → Конфиденциальность
> и безопасность**, прокрутите вниз — там будет кнопка «Открыть всё равно».

## Шаг 2 — Дать разрешение микрофону

При первой попытке распознавания macOS спросит разрешение на доступ к
микрофону. Нажмите **Разрешить**.

Если случайно нажали «Запретить», откройте:

**Системные настройки → Конфиденциальность и безопасность → Микрофон**

В списке найдите **Dikto Pro** и включите тумблер. Приложение нужно будет
перезапустить через значок в строке меню → «Выход».

## Шаг 3 — Дать разрешение «Универсальному доступу»

Чтобы вставить распознанный текст в активное окно, Dikto Pro нужно
эмулировать нажатие ⌘V. Для этого macOS требует разрешение
**Универсальный доступ (Accessibility)**.

Приложение само откроет нужную страницу настроек при первом запуске.

**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**

Найдите **Dikto Pro** в списке и включите тумблер. Если приложения в
списке нет — нажмите **+** и выберите его в папке «Программы».

## Шаг 4 — Найти значок в строке меню

После выдачи разрешений в правом верхнем углу появится значок с волной.
Кликните по нему — увидите статус «Готово», текущую горячую клавишу и
оставшиеся дни триала.

Если значка нет — приложение могло не запуститься. Откройте Терминал и
выполните `open -a "Dikto Pro"`.

## Шаг 5 — Попробовать диктовку

1. Откройте любое приложение с текстовым полем — Заметки, браузер,
   почта.
2. Кликните в поле, чтобы установить курсор.
3. Зажмите **правый Option (⌥)**.
4. Скажите: «Привет, это первая диктовка через Dikto Pro».
5. Отпустите Option.
6. Через секунду текст появится в курсоре.

## Шаг 6 — Активировать лицензию

В правом верхнем углу строки меню кликните по значку Dikto Pro →
**Активировать...**.

В появившемся окне:

1. Вставьте лицензионный ключ из письма (формат `XXXX-XXXX-XXXX-XXXX`).
2. Нажмите **Активировать**.

Приложение проверит ключ на сервере (один HTTPS-запрос) и сохранит
лицензию в системную связку ключей (Keychain). Дальше до 14 дней без
сети ключ работает локально; затем — повторная сверка с сервером.

## Если что-то пошло не так

### Глобус ⌘ открывает emoji вместо записи

В macOS клавиша 🌐 по умолчанию открывает emoji-picker. Поменяйте:

**Системные настройки → Клавиатура → Когда нажат 🌐 → Не делать ничего**

### Распознаёт, но не вставляет

Проверьте разрешение «Универсальный доступ». Если оно есть, но не
работает — попробуйте выключить тумблер, подождать секунду, включить
обратно. Иногда macOS «забывает» разрешение между обновлениями.

### Звук пишется, но текст пустой

Скорее всего, говорите слишком тихо или микрофон занят другой программой.
Проверьте в **Системных настройках → Звук → Вход** уровень входа. Полоска
должна заметно шевелиться при разговоре.

### Активация не проходит

- Проверьте интернет: ключ нужен только при активации.
- Убедитесь, что в ключе нет пробелов и переносов — копируйте целиком из
  письма.
- Если ошибка «Лимит устройств для этого ключа исчерпан» — напишите на
  support@itbeaver.co, мы освободим слот.

## Удалить Dikto Pro

1. Закройте приложение (значок в меню → «Выход»).
2. Перетащите **Dikto Pro** из «Программ» в корзину.
3. (Опционально) Удалите данные приложения:
   - `~/Library/Application Support/Dikto/` — модели и история записей
   - `~/Library/Mobile Documents/com~apple~CloudDocs/Dikto/config.json` —
     конфиг

Лицензионный ключ в Keychain тоже останется — удалить можно через
«Связка ключей» → найти `co.itbeaver.dikto.license`.
